## AI developer tools

### OmniCLI

I can give a team of coding agents one goal from my terminal. A lead breaks it into tasks, workers edit the project, and OmniCLI runs each task’s checks before the lead reviews the changes. Git checkpoints let me look back at exactly what each worker delivered. [Source and quick start](https://github.com/Kartik-99999/mniCLI) · [See the terminal interface](https://github.com/Kartik-99999/mniCLI/blob/main/docs/chat.png)

### Project Chimera

I built a referee for browser agents that checks what happened on the page. In a 30-run experiment on a single workflow, Muse Spark claimed success 20 times. The referee confirmed 18 and caught two cases where the agent had created duplicates. [Source](https://github.com/Kartik-99999/project-chimera) · [Three-minute demo](https://github.com/Kartik-99999/project-chimera/releases/tag/v1.0-demo) · [Experiment and results](https://github.com/Kartik-99999/project-chimera/blob/main/experiments/model-baseline-v1/REPORT.md)

## Systems and applications

- **PRAHARÍ** connects unusual events across a network so an analyst can follow an incident and audit the response. Its detector scored 0.845 macro ROC-AUC across the DDoS and port-scan evaluations on held-out CIC-IDS-2017 data. [Source](https://github.com/Kartik-99999/prahari) · [Verification report](https://github.com/Kartik-99999/prahari/blob/main/VERIFICATION_REPORT.md)
- **School ERP** gives each school its own subdomain on one FastAPI and Next.js deployment. Admissions staff can turn an accepted application into a student record, and students can check attendance and fees through their portal. [Source](https://github.com/Kartik-99999/School-Erp) · [Architecture and implementation](https://github.com/Kartik-99999/School-Erp/blob/main/PROJECT_OVERVIEW.md)
- **DefencePost** is an independent Indian defence publication. I built the reader-facing site and the pipeline that gathers stories, prepares articles, and publishes them each morning. [Read the publication](https://www.defencepost.live) · [Front end](https://github.com/Kartik-99999/defence_post) · [Publishing pipeline](https://github.com/Kartik-99999/defencepost-automation)
- **CelebrationCraft** turns someone’s photos and message into a personalised event website. The four-step order flow includes template selection, Razorpay checkout, and WhatsApp delivery. [Try the site](https://celebrationcraft.vercel.app) · [Source](https://github.com/Kartik-99999/celebrationcraft)

I also built a **data structures visualizer** with Bhavya, Ishika, and Rishika. Its browser interface drives a C++ backend so you can step through operations on linked lists, stacks, and queues.
